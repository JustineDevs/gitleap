# GitLeap

GitLeap transforms a public GitHub repository pinned to an immutable commit into an evidence-backed, downloadable skill pack. The pipeline fetches source without executing it, builds a deterministic inventory, synthesizes bounded skill metadata, validates the result, and stores the archive privately.
